# 商场AI经营分析系统 - 使用说明

## 一、系统简介
本系统用于商场每日销售数据的自动统计、盈利分析及AI运营建议生成。  
- 支持从旧POS系统导出Excel/CSV导入数据（自动兼容GBK编码与中英文表头）  
- 基于本地大模型（默认 qwen2.5:7b）生成中文运营策略  
- 提供领导看板（品类占比、30天趋势），支持Excel和PDF报表导出  
- 完全本地化部署，可断网运行

## 二、环境要求
- **系统**：Windows 10/11（Docker Desktop）或 Linux 服务器，已安装 Docker Compose (v2.0+)  
- **显卡**：8GB 显存即可（如 RTX 5070 Laptop）；如需运行 14B 模型则要 16GB 以上显存  
- **模型**：推荐 qwen2.5:7b（4.7GB，可全量进入 8GB 显存）；容器内不再跑 Ollama，直接复用宿主机已装好的 Ollama 服务  
- **断网可用**：模型已下载到本地，AI 推理不依赖任何外部服务；首次部署后可拔网线运行

### 本机部署说明（Ollama 复用宿主机服务）
- 8GB 显存跑不动 qwen2.5:14b，系统默认使用已下载的 **qwen2.5:7b**（4.7GB，可全量进入显存）
- Docker 里的后端通过 `host.docker.internal` 连接宿主机上的 Ollama，因此 Ollama 必须对网络监听：
  1. 设置用户环境变量 `OLLAMA_HOST=0.0.0.0` 并重启 Ollama（托盘退出后重开），
     或在 Ollama 设置界面勾选 "Expose Ollama to the network"
  2. Windows 防火墙放行 11434 入站端口
  3. 验证：`netstat -ano | findstr 11434` 应显示 `0.0.0.0:11434` 而不是 `127.0.0.1:11434`
- 排障：访问 `http://localhost:8000/api/health`，返回 `"ollama_ok": true` 即链路正常
- 断网可用：模型已下载到本地，AI 推理不依赖任何外部服务
